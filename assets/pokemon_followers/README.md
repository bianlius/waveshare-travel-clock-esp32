新增的四足奔跑伙伴（水跃鱼、雷电兽、可可多拉、土狼犬、向尾喵、阿勃梭鲁、小火焰猴、帕奇利兹、索罗亚、单首龙、火斑喵）统一改为 80／120 毫秒交替计时，平均每帧 100 毫秒，为原始 120 毫秒的 1.2 倍动作速度；首页与商店预览共用这一节奏。原有 9 只伙伴保持现有速度，其他直接循环动作每帧 120 毫秒、往返循环动作每帧 160 毫秒；具体时间和循环顺序以 manifest 为准。巴大蝶选用顶排完整振翅循环，波加曼选用中排奔跑动作，铁面忍者选用左上两帧小幅振翅动作。这些动画保持各自的既定计时序列，首页往返移动不改变动画速度。

四足奔跑按 manifest 的 `playback_sequence` 和 `playback_ticks` 播放，奇数姿势的动画连续安排两轮，使 80／120 毫秒计时在循环边界也持续交替；源 PNG、姿势顺序和所有像素不变。

循环中的相同像素帧通过 GVIEW 原有的零高度引用帧复用；时间轴、帧数、支点和颜色保持完整，不在运行时解压，也不为重复姿势另占图像存储。`followers.h` 与 `followers_decl.h` 都由打包器生成。

拥有记录在旧 64 位字段后追加 64 位扩展，覆盖编号 0–127。旧物品字段、装备编号和服装偏移保持不变；版本标记使用原先的尾部填充，扩展从旧记录末尾 88 字节之后开始，新的记录为 96 字节。旧存档首次读取时仅将新增拥有位初始化为零，保留已有伙伴、金币和服装；不会继承任何退役编号的拥有记录。编号 64–70 的购买、装备、保存和重读均有自动检查，包含五种新增洛托姆形态。

本批修改前的素材和相关程序保存在 `artifacts/firmware/downloaded-pokemon-2026-11-14/before/`。下载原文件不修改；manifest 保存每张原图的文件名、SHA-256、拆帧选区、身体支点、地面基线与循环顺序，后续可直接调整配方重新生成。
